## 🚀 Featured Projects

### 🔹 AI Interview Simulator
**Python · LangChain · FAISS · MiniLM · Ollama · FastAPI · SQLite**

An AI-powered interview evaluation system developed as my final-year project.

- Generates personalized interview questions based on candidate resumes and extracted skills.
- Uses a RAG pipeline with FAISS and MiniLM embeddings for context-aware question generation.
- Integrates locally hosted LLMs using Ollama.
- Evaluates candidate answers using a structured five-criteria grading rubric.
- Uses FastAPI and SQLite for backend processing and score storage.

---

### 🔹 AI-Powered Document Q&A System
**Python · LangChain · FAISS · RAG · Hugging Face**

A document question-answering application that allows users to ask questions about PDFs and text documents in natural language.

- Retrieves relevant passages from documents to provide context-aware responses.
- Uses FAISS for vector-based semantic search.
- Uses LangChain for retrieval and LLM orchestration.

### 🔹 LangChain CSV Agent
**Python · LangChain · Ollama · ReAct**

An AI-powered agent that allows users to analyze CSV datasets using natural-language queries.
